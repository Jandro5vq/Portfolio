## Projects

### WiseLogger

Self-hosted work-time tracker: shifts, tasks, automatic breaks, a Gantt-style timeline, history and stats of hours worked versus expected. It includes an MCP server so AI assistants such as Claude or Copilot can log tasks for you.

TypeScript · Next.js · SQLite · Drizzle · MCP · Docker

[View the code](https://github.com/Jandro5vq/WiseLogger)

### Foundry Price Checker

Terminal UI to search, compare and sort Azure AI Foundry model prices per million tokens, enriched with context window, capabilities and LMArena Elo rating. Exports to CSV.

Rust · TUI · Azure · REST APIs

[View the code](https://github.com/Jandro5vq/foundry-price-checker)

### OctoPrint GPIO PSU Control

OctoPrint plugin that switches a 3D printer's power supply on and off from a Raspberry Pi's GPIO: auto-on at startup, auto-connect to the printer, auto-off after printing, and an HTTP API.

Python · Raspberry Pi · OctoPrint · Jinja

[View the code](https://github.com/Jandro5vq/OctoPrint-GPIO-PSUControl)

### InnoCraft

Fabric modpack for Minecraft 1.21.1 that updates itself in Prism Launcher, published with packwiz and GitHub Pages, with scripts to build and release each version with its changelog.

Python · Shell · GitHub Pages · packwiz

[View the code](https://github.com/Jandro5vq/InnoCraft)

### Pill Assistant

Smart pill box for elderly people who find it hard to remember which pill to take and when. A family member sets it up from the app, so the person using it doesn't have to worry about anything.

Hardware · App

[View the project](https://github.com/Jandro5vq/Pill-Assitant)

### This campfire

This very portfolio: a forest drawn on canvas with music generated in the browser.

Canvas · Web Audio · JavaScript

[View the code](https://github.com/Jandro5vq/Portfolio)
